# 投稿素材稿 · 小众软件 / Appinn

**标题**：知藏 ZhiVault —— 把知乎装进自己口袋：免登录采集 + 版本历史 diff + 全文检索的存档工具

**正文**：

知乎内容消失的风险一直在：删帖无通知、封号不可逆、大 V 销号。官方只提供账号资料级副本，十年没人做顺手的全量存档工具——知乎助手补了采集半边，但没有评论、没有整问题、只存最新版。知藏想把这个拼图补完。

**是什么**：Windows 绿色单文件（<30MB，便携），把知乎公开内容采到本地 SQLite：

- 免登录采公开内容：回答/文章/想法/整问题（含评论树）/收藏夹/专栏/话题/用户主页，批量粘贴整批跑，断点续抓
- **版本历史**：内容被修改自动留旧版，任选两版并排 diff；被删内容本地留档
- FTS5 全文检索 + sandbox 阅读器 + 四色标注（跨版本指纹锚定）
- 导出 HTML/EPUB/Markdown/TXT/DOCX/PDF/JSON，RAG 模式 JSON 存原始响应，Obsidian Vault 一键导出
- 定时监控 cron + 运行时段 + 补跑，命中更新系统通知
- AI 摘要/标签（自带 DeepSeek/OpenAI 兼容 Key）

**安全**：凭据 DPAPI 加密、日志脱敏、更新包 Ed25519 签名校验、SSRF 白名单、导出内容脚本清除。核心引擎 MIT 开源可审计。

**合规边界**：仅限个人学习存档；内置限速默认 1 req/s 不可关闭到危险值；不碰盐选等付费内容；不绕过人机验证。
