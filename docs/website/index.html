功能

免登录采集

回答/文章/想法/整问题/收藏夹/专栏/话题/用户主页，批量粘贴整批启动；匿名可采公开内容，登录可选。

增量 + 断点续抓

二次运行只抓新增与更新；中断后从游标恢复，已完成不重复。

版本历史 diff

内容被修改自动留旧版，任选两版本并排对比；被删内容本地留档。

评论树

回复层级完整导出，支持赞数筛选——对手没有的拼图。

全文检索 + 标注

FTS5 中文检索高亮；阅读器 sandbox 隔离渲染，四色高亮批注，跨版本指纹锚定。

七格式导出

HTML/EPUB/Markdown/TXT/DOCX/PDF/JSON，RAG 友好；Obsidian Vault 一键导出。

定时监控

cron 预设/自定义 + 运行时段 + 补跑策略，命中更新系统通知。

AI 摘要标签

自带 DeepSeek/OpenAI 兼容 Key，生成记录可回溯可导出。

安全承诺

凭据 DPAPI 加密

本机加密落盘，注销一键清除；日志全链路脱敏。

更新包签名校验

Ed25519 + SHA-256 双校验，篡改必拒；更新请求零凭据。

本地优先

数据全在本地便携目录，整目录复制即迁移；不做云同步。
