# 知藏 ZhiVault —— 用户手册

> 把知乎装进自己口袋 · 作者：橙茶星 · v0.1.0

## 1. 安装与启动

绿色免安装：解压 `zhivault-x.x.x-x64.zip` 到任意目录（建议非 Program Files），运行 `zhivault.exe`。

- 首次启动需阅读并同意使用协议（不可跳过）
- Windows 11 自带 WebView2；若提示缺失请安装 [WebView2 运行时](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution)
- 首次运行如遇 SmartScreen：更多信息 → 仍要运行（未购签名证书，声誉自动积累中）

## 2. 快速上手（三分钟）

1. **粘贴链接**：首页粘贴知乎 URL（回答/问题/收藏夹/专栏/话题/用户主页），自动识别类型 → 添加任务；可一次粘贴多行或从 `.txt` 文件导入批量
2. **开始运行**：右下角「开始运行」。匿名即可采公开内容；实时看速度/计数/日志
3. **书架检索**：顶栏检索（中文 ≥3 字），类型+时间范围组合筛选，点击「打开阅读」
4. **导出**：导出中心勾选书源与格式 → 出书到所选目录

## 3. 采集

- **任务类型**：回答 / 文章 / 想法 / 问题（整问题全量，赞同或时间排序，可截断上限）/ 收藏夹 / 专栏 / 话题 / 用户（公开创作匿名可采；赞同动态需登录）
- **匿名/登录**：右侧栏「匿名 · 点击登录」打开弹层；登录粘贴 Cookie（开发者工具 → 网络 → 请求头复制），凭据 DPAPI 加密保存本机；「注销并清除凭据」二次确认后全清除
- **增量**：同一任务第二次运行只处理新增/更新；内容变化自动进版本历史
- **断点续抓**：暂停/退出后重新运行，从上次游标继续，已完成不重复
- **图片**：设置里选 原图 / 压缩 WebP / 无图；图片池跨任务去重

## 4. 书架与阅读器

- **检索**：FTS5 trigram 中文分词；查询词整词高亮；类型 + 创建时间范围筛选
- **阅读器**：正文 sandbox 隔离渲染（安全）；划词弹出标注气泡，四色 + 批注
- **标注锚定**：以选中文本前后 32 字符指纹定位；内容被修改后自动降级段落级锚点；大幅修改会提示
- **版本时间线**：右栏「版本」勾选任意两版 → 并排 diff（删除红/新增绿）

## 5. 变更报告

每次运行一行（来源/已抓/新增/修改/未变/失败），展开即本次产生的全部修订清单，点击直达阅读器 diff。监控计划与手动运行共用同一数据源。

## 6. 导出中心

- **书源**：全部内容合并 / 仅回答 / 仅文章 / 仅想法 / 仅问题
- **格式**：HTML（单文件，页脚署名）/ EPUB（dc:creator 署名，>10000 条自动分卷）/ Markdown（front-matter + 图片 assets/）/ TXT / DOCX / PDF（需系统 Edge）/ JSON（schema v1，含原始响应，RAG 友好）
- **partial 语义**：单个格式失败不影响其他格式，报告中如实标注
- **导出历史**：最近 50 条，格式选择自动记忆

## 7. 监控计划

新建计划：名称 + 目标 URL（每行一个）+ 频率（每天/每周/每月/自定义 cron/自定义间隔）+ 运行时段（可空，支持跨午夜）+ 补跑策略（错过跳过 / 启动补跑）。到点自动增量，命中更新弹系统通知。应用运行期间生效。

## 8. AI 中心

配置 DeepSeek/OpenAI 兼容 Key（DPAPI 加密）与模型/端点 → 输入实体 ID 生成摘要与标签 → 记录可回溯、可导出 JSON、用量按模型统计。自定义端点需用户显式配置（SSRF 白名单例外）。

## 9. 设置

- 主题：浅色 / 深色 / 跟随系统
- 限速档位：保守 0.5 / 标准 1 / 激进 2 req/s（不可关闭到危险值；触发 429/风控自动退避 0.2 并提示）
- 数据目录：便携模式 `exe 旁 zhivault-data/`，整目录复制即迁移
- 诊断导出：日志自动脱敏后导出

## 10. 常见问题

**Q：必须登录吗？** 不需要。公开回答/文章/想法/问题/专栏/话题/公开收藏夹/用户公开创作均可匿名采集；赞同动态等个人内容需登录。

**Q：触发风控怎么办？** 软件自动退避到 0.2 req/s 并在运行页提示，请稍后再试；请勿手动绕过验证。

**Q：换电脑怎么办？** 复制整个文件夹（含 `zhivault-data/`）到新电脑，原样可用。

**Q：误删了内容还能找回来吗？** 只要采过，版本历史里留档；被删内容的最后一个版本仍在本地库中。

**Q：会碰盐选付费内容吗？** 不会，产品边界明确排除，协议层已声明。
