# 投稿素材稿 · V2EX

**标题**：[开源] 知乎存档工具 · 知藏 ZhiVault：免登录采集 / 版本历史 diff / 中文全文检索，绿色 <30MB

**正文**：

把知乎装进自己口袋。对手（知乎助手）多年没解决的几个点，知藏首发补齐：

- **评论树导出** + **整问题全量**（issue 区索要多年未果的两块）
- **版本历史**：被修改留旧版、任选两版并排 diff、被删本地留档——"备份只存现在，存档保存历史"
- 免登录采公开内容；增量 + 断点续抓；FTS5 中文检索高亮；阅读器 sandbox + 标注
- 七格式导出（JSON 存原始响应，直接喂 RAG）+ Obsidian Vault
- 定时监控 + 命中系统通知；AI 摘要标签（自带 Key）

技术栈：Tauri 2 + React + TS，壳 <500 行 Rust；FTS5 trigram；pandoc-wasm 导出；Edge 无头打印 PDF。
安全：DPAPI 凭据、更新包 Ed25519 校验、SSRF 白名单、日志脱敏。核心引擎 MIT。

合规：个人用途协议不可跳过、限速 1 req/s 内建、不碰盐选、不绕过人机验证。

绿色免安装，Release 附 SHA-256。作者：橙茶星，欢迎拍砖。
